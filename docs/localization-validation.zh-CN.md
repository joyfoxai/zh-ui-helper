真实部署前的专用测试证书创建与本机信任由维护者分步完成，再使用发行安装脚本的现有证书分支。不能把这段实测描述为默认首次创建证书命令已完整实跑。PowerShell 模拟检查不会创建系统证书或更改信任。

脚本不修改执行策略，不自动 UAC 提权。`-TrustCertificate` 及计算机证书清理要求管理员窗口，只接受专用发布者的有效代码签名证书。自签证书私钥不可导出，只输出公钥 CER；不向受信任根存储写入。

恢复依赖 `lifecycle-audit.json`，按安装记录校验修改包、快捷方式及证书所有权。默认保留证书，显式 `-RemoveTestCertificate` 才尝试精确清理；已有或被其他包使用的证书不会当作本次独占资源删除。本轮实际卸载未重复执行，预览与相关保护由模拟检查覆盖。

## 更新行为与边界

不使用固定 Claude 版本白名单或历史构建哈希放行表。安装器检测当前真实主包身份和资源结构，记录实际源文件摘要用于完整性校验，不因版本号变化而直接拒绝。

资源通过包含当前真实 PackageFullName 的 VFS 路径覆盖。官方更新改变完整包名后，旧路径不会覆盖新包；需移除旧修改包，再为当前版本重新构建和应用。不能把这一设计描述为所有未来版本自动兼容。

本项目尚未穷尽验证全部功能、任务类型、连接器、权限弹窗、异常状态和窗口尺寸。官方账户远程网页模式、ARM64、macOS、Linux、其他 Windows / Claude 版本尚未完成实机验证。外部网页、终端输出、工具结果、用户内容和模型回复保持原文；新文案可能显示英文。

早期普通目录副本方案已由本次资源包方案替换，相关安装入口不再随新版分发。当前结论以中文状态下实际任务证据为依据，不以切换其他语言作为修复证明。
